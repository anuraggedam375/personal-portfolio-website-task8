# Web Development Internship Tasks — VS Code Project

This project completes **Tasks 1–4** from the supplied internship PDF (the minimum required is any four tasks).

## Included tasks
1. **Personal Portfolio** — `portfolio.html`: intro/bio, education placeholder guidance, skills, project cards and contact link. Replace `[Your Name]` and the photo placeholder with your own details.
2. **Responsive Landing Page** — `index.html`: Nova fictional product homepage with header, feature highlights, testimonial and footer. Uses CSS Grid/Flexbox and responsive media queries.
3. **Google Homepage UI Clone** — `google.html`: static search homepage recreation; search is intentionally non-functional as allowed by the task.
4. **Form + JavaScript Validation** — `contact.html`: name, email, phone and message fields with client-side validation and feedback. Demo only; no backend/email sending.

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted `web_development_internship_tasks` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and click **Go Live**.
4. Use the footer links to open the other task pages.

## Before submitting
- Replace `[Your Name]` and the photo placeholder in `portfolio.html`.
- Add your real education details and update skills/projects to reflect your own work.
- Test the pages at desktop and mobile widths.
- Record a short walkthrough video and post it on LinkedIn, tagging **Kodbud** (required by the supplied brief).
- GitHub upload is optional but recommended. Submit the project link(s) through the Task Submission Form sent by email.
